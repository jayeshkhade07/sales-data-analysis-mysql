# Sales Data Analysis Using MySQL

## Project Overview
This project focuses on analyzing sales data using MySQL queries to understand sales performance across products, categories, and cities.

## Tools Used
- MySQL 8.0
- MySQL Workbench
- GitHub

## Dataset Details
The dataset contains the following columns:
- Sale ID
- Product Name
- Category
- Quantity
- Price
- Sale Date
- City

## Key Analysis
- Total Sales Analysis
- City-wise Sales Analysis
- Category-wise Sales Analysis
- Product-wise Sales Analysis
- Monthly Sales Analysis
- Average Product Price Analysis
- Highest and Lowest Sales Analysis

## SQL Concepts Used
- CREATE DATABASE
- CREATE TABLE
- INSERT, UPDATE, DELETE
- SELECT
- WHERE
- GROUP BY
- ORDER BY
- HAVING
- Aggregate Functions
- Date Functions
- LIMIT

## Project Files
- sales_data_analysis.sql – SQL script containing the database setup, sample data, and analysis queries.
